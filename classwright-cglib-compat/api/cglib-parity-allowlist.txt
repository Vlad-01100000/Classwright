# CGLib 3.3.0 API elements this module deliberately does not reproduce exactly.
#
# Checked by CglibApiParityTest: the real CGLib jar is diffed against this module by complete
# erased JVM descriptors (name, parameters AND return type), visibility rank, checked
# exceptions, field attributes and constant values. Every gap must appear here, with its
# reason, or the build fails. Deleting a line re-arms the check for that element; an entry
# ending in * matches by prefix and is used only for subtrees that are out of scope wholesale,
# never for packages this module partially covers - a wildcard there would let a real
# regression hide behind it.
#
# The categories, in the compatibility vocabulary of docs/MIGRATION.md:
#
#   [ASM]         The element's signature names org.objectweb.asm types. Reproducing it means
#                 taking the ASM dependency whose pinned shading ended CGLib. UNSUPPORTED.
#   [GEN-SPI]     CGLib's AbstractClassGenerator machinery: protected hooks and supertypes of
#                 the generator classes. Classwright's engine is a different architecture and
#                 these hooks have no meaning in it. UNSUPPORTED.
#   [SOURCE-USAGE-DEPENDENT] The member exists and behaves equivalently, but its JVM return
#                 descriptor differs (a facade returns Object or a native Classwright type
#                 where CGLib returned its own class, which generated subclasses made
#                 possible). Two consequences, stated precisely: precompiled bytecode linking
#                 CGLib's descriptor for one of THESE members does not link and needs
#                 rebuilding; and after recompilation, the common factory-cast usage
#                 ((MyKey) KeyFactory.create(...)) compiles and runs unchanged, but source
#                 that assigns the result to CGLib's own type (KeyFactory f = ...;
#                 Mixin m = ...) no longer compiles and needs a source edit. Every member in
#                 this category is listed so the boundary is known, not guessed.
#   [SUBCLASS]    Protected constructors/fields that existed for CGLib's *generated*
#                 subclasses. Classwright's generated classes extend the native
#                 com.classwright types instead, so this plumbing has nothing to serve.
#                 INTENTIONAL GAP.
#   [FACADE]      The compat class is a factory facade whose products are native Classwright
#                 objects; the instance-side surface lives on the native type, documented in
#                 each class's javadoc. INTENTIONAL GAP (source-visible).
#   [BEANS-MIXIN] STYLE_BEANS mixins need a bean-property mixin generator the native library
#                 does not have yet; candidate for a later release. UNSUPPORTED for now.
#   [INTERNAL]    CGLib's ASM-era emitter/utility toolbox: public in the jar, internal in
#                 nature. Classwright's equivalents are its own com.classwright.core engine.
#                 UNSUPPORTED.
